# 卷一 《喧嚣区》 · 第014章 还没盘出来

第五声鸣滚过去，场里的人各自归了位，像退水淌回坑里。

饿到第三日，挪一步费一步的劲，可满场没一个真闲着的。眼睛都在动：看腕的，数人的，往没答的那四个位子上瞟的。嘴也有动的——墙根底下，又有人拿气声试"还不上"。试到"还"字，照旧卡住，自个儿把嘴闭了。这一晌满场试的人不少，没一个试全的。皮夹克兜里那句是实底；旁人舌头上垫的净是虚的，垫不住。

水队那头，出了桩新鲜事。

应真的嘴，闲下来了。

他照旧分水，照旧扶碗，队排歪了照旧伸手扒拉。可那跟着水走了几日的话，没了。接慢了的，他摆摆手；凑一堆咬耳朵的，他隔开；今儿一个字没多给。分水的手还是匀的，只是每回空下来，就往自个儿腕上搭一回。搭上去，又拿开，像试一块烧过的铁。

老周挨着闻歧，掰着指头把没答的又数了一遍。数到水队那头，停住了。

"水边那个，今儿不对。"他压着嗓子，"话呢？他那张嘴，几日没闲过。"

"在盘账。"闻歧说。

"盘啥账？"

闻歧没接。他看了两眼就有数了：满场都在替自个儿慌——看腕的、试话的、扒拉指头的，慌的全是那点数。就应真一个人，盘的是账本身。他那个三十九不低，掉得起两回，他盘的不是数。

这话闻歧没往外说。说出去，又是替人答题。

三步地界外，摸耳朵的手还在膝盖上按着。老周前头那句"死活不上秤"，没人接，也没散——它就搁在当间，跟那块平平整整的浮土搁在一块儿。没人再看它，可谁都没忘了它。

台阶上，郑桂香的眼睛也搁在水队那头。她那五个字传到队尾就传不动了——水队今儿静，静得没处递话。

皮夹克坐在墙根明处，眼睛从闻歧的袖口上挪开，挪到了水队。他盯水队不是头一回——上一回等的是个练话的露头，这一回等的还不知道是个啥。低值的货他多看两眼；会盘账的人，比低值的货稀罕。

雷阖在观察角上没动。他的眼睛今儿也在水队那头搁得久。本子收在怀里，没掏。

墙外头，潮声一涨，一落。回回匀。

第六声鸣，贴着屋脊滚了过来。

起身的，比上一回齐。上一回有两三个坐着没动，眼睛先醒，身子慢半拍；这一回鸣声还没滚完，人已经站起来了。谁也没说破为啥。数能往回长这么一件事，比啥都养记性。

记账人就在这片齐整的动静里现了身。人和秤一齐拧出当间，秤杆上那道细丝丝的偏差，还挂在老地方。

"续。"

没人应。

"谁先来，谁先说。"

满场静了一息。看腕的风照旧刮，从东墙根刮到台阶，刮过水队——

水队那头，先有了动静。

应真把手里最后一只碗摞上，摞得比平时轻。他没急着走，先把跟前的碗从头数了一遍，数完，两只手掌在裤腿上蹭了蹭，蹭得挺认真，像把手上的水蹭干，又像把别的什么蹭干净。

然后他站起来，回头冲队里说了一句："排好。谁也不许抢。水是水，账是账。"

女孩坐在兽嘴边上，把那只空碗往怀里拢了拢。

应真这才转身，往当间走。

走到秤跟前，站定。

站得不远不近，跟分水排碗一个讲究。两只手在裤腿上又蹭了一回，这回是把手上真剩下的那点水蹭干。

他那闲了半晌的嘴，这会儿倒像不知道打哪儿起头。他不急，眼睛在秤上搁了搁，又挪回自个儿手上。

"我爹这辈子，没见过海。"他说，"我答应过他，带他去。日子都挑好了。这事我记得门儿清——偏偏我想不起他长啥样了。"

场里有人把眼睛低了下去。想不起——这毛病满场都有，谁也不笑话谁。

"后来我琢磨明白了。"应真说，"我欠他的不是海。海搁哪儿都有。我欠他的，是领他去的那条路，我没领他走。"

他抬起手，从衣领里头摸出个东西。

一只贝壳。麻绳拴着，磨得发亮——贴身挂的，一挂就不是一年两年。满场的眼睛都聚了过去：翻包那回，帆布包里抖出来的是旧衣、麻绳、粗布。原来包是空的，脖子上贴身藏着东西。

"他没等到。"应真说。就四个字，没往下讲。他把贝壳攥进手心，攥得挺实。

女孩把怀里的空碗拢紧了。

"海，我拿不出。这城里没有。"应真说，"可墙外头有。"

他侧过身，冲着墙。攥贝壳的那只手，跟着抬起来，指着墙。

潮声正涨。一涨，一落，回回匀。这几日这声音一直搁在墙外头，饿的人没心思理会。这会儿，满场都听见了。

"爹。"他冲着墙说，还是分水那个嗓，只是慢了，"涨了。"

顿了顿，又补一句，像闲话，又像交代账目：

"往后每回涨，我替你听一回。一天听一回，总有听够数的那天。"

秤动了。

话音落，秤就动。不快不慢，跟给旁人判时一个样。杆子抬起来，落定。应真腕上，三十九添成了四十。那道细丝丝的偏差还挂在老地方，一丝没多。

满场呼出一口气。不是叹，是憋了半晌，松开了。

"借的能过，攒的能过，还不上也能过。"台阶上，郑桂香擦了一回围裙，这回擦的是手，"人家这个，叫有货。"

老周挨着闻歧，指头在膝盖上比划了半天，压着嗓子："把话还了……不是，他把潮还了？"他自己绕不圆，摇了摇头，"这个俺不掰了。掰不动。"

闻歧没接话。他看的不是应真，是秤——话音落即动，跟这几日每一回一样。记下了。眼睛这才挪到那只贝壳上，又挪开。贴身挂了不是一年两年的东西，敢当满场亮出来；这一亮，比那四十还不轻。

水队那头，女孩把下巴搁在空碗沿上。她那句是话，应真这个不光是话——是把日子掰成一日一听，慢慢还。她未必看得懂这些，她只觉得水边这个人，往后每回潮涨，都有一件事要做。有事情做的人，饿着，也站得直。

三步地界外，摸耳朵的手又抬起来了。

这回比上回高，过了心口，眼看要够着耳朵——半道上，又落回膝盖。可就这半道，满场低值的眼睛全跟着晃了一下。五十六，不低。可他那会儿看应真的眼神，闻歧认得：饿的人，在看一个找着活路的人吃饭。

墙根明处，皮夹克的指腹在裤缝上点了点。没掐道子，就是点了点。像掌柜见了没见过的货，先不还价，先记账。

雷阖的眼睛从水队挪开了。头一回，落在墙上。

墙外头，潮声落了一拍，又涨起来。满场没人说话。满场的耳朵，都还冲着墙那边留着。
