# 卷一 《喧嚣区》 · 第021章 路头是海

第八声鸣，贴着屋脊滚过来。

人没先动，耳朵先立起来。饿到第四日，连那半寸都省了：身子贴着墙根，等鸣滚完。

记账人随鸣现身。秤落当间，杆上照旧差着那一丝。

"续。"

"谁先来，谁先说。"

两句话落下去，满场先动的还是眼睛。老规矩，顺低处捋：袖口的七，观察角的十三，再往上，三十九、四十挨个过。捋到头，又落回袖口，搁住。第五题剩四个，四个都知道自己是谁，谁也不先动。

道口那边，三个坐的都没挪。老者脸冲外，眼睛还搁在那截空上——四天晷没动静的空，他照样瞧。皮夹克守着对面，手摊在膝盖上，指头松着。中间那截袖口拢在腕子上，没动。问收了口，瞧还长着；这会儿谁先起身，谁的身上就得落满眼睛，落到答完为止。

观察角那头，手还压在本子上，没掀。

兽嘴那头，碗声照旧。

四天晷，场里能挪的都挪过——坐处挪了，眼睛挪了，人挪了好几茬；碗声没挪过。应真手底下，碗一只一只码，码得齐齐的。饿到第四日，码到顶上那只，手悬过半息；悬完，落稳，还是齐的。

今儿码到一半，停了。

不是悬——是停。应真两只手按在碗沿上，按了一息，又按一息。满场耳朵先竖起来：碗声停了，四天晷头一回。耳朵后头，眼睛才跟上——他把那只碗搁上垛顶，两手在裤腿上抹了一把，扶着膝盖，站起来了。

他没先看秤，先回头望了一眼墙根。女孩搂着空碗，冲他点了一下头。点得很小，像替谁先把口气攒上了。

从兽嘴到当间，几十步。应真这张嘴，四天晷没让它闲过半天；这一路，一个字没说。满场头一回见他闭着嘴走这么远。

到秤前站定，他先看腕。四十。他看了它一眼，不看道口，也不看满场——像下水前先把衣裳系紧。

"这题问的是路。"嗓门还是那个亮嗓，没人接话，反倒亮得齐整，"那俺打路头背。"

他顿了顿。

"俺的路头，是俺爹要看海。"

满场静了一息，没人接话。他也不等人接——这张嘴，四天晷头一回不为接话使唤。

"俺们那儿是旱地。出门是梁，翻过梁，还是梁。俺爹给人赶了半辈子车，车上装过盐，装过炭，装过人家的嫁妆，就没装过他自个儿想去的地儿。他就惦记一样——海。打俺记事起就念叨，念叨得俺都能背：海是宽的，海是咸的，海那头，没准儿还有个啥。"

"有一年他撂下车辕，跟俺说：等你闲了，领俺去看看。"

"俺应了。应得那叫一个痛快——中！秋收了就去。"

"秋收完了有麦，麦完了有钱粮，钱粮完了，家里又添了张吃饭的嘴。"他一样一样数，数得不快，跟码碗一个数法，"俺不是忘了。俺是想，日子长着呢，海又跑不了。"

"一年，一年，又一年。"

说到这儿，他停了。满场都等他找补——谁的话他都能接半句的人，这会儿话头悬着。台阶上，郑桂香的手抬了半寸，像要替他把话递过去。道口那边，老者没回头，眼皮抬了一下，又落回那截空上。

他没找补。也有人等着他摸领子——那枚贝壳上一晷当众亮过，满场都记得它的分量。他也没摸。两只手贴着裤缝，哪只都没动。嗓门还是那个亮嗓，只是里头没垫东西了：

"末了那年，俺到了他炕跟前，想说句宽心的——爹，开春，开春俺真领你去。俺低头瞧他——"

他顿住。这一顿，比先前所有的停都长。

"那张脸——黑的。俺想不起来。"

"瞧了半辈子的脸，俺想不起来。宽心话也没说出口——对着一张想不起来的脸，俺不知道该往哪儿搁。"

"这就是俺的路：他要看海，俺说中；一年推一年，推到末了，海没看成，脸也没了。"他看着腕子，"路俺背到这儿。后头是黑的。俺不添。"

话音落，秤动了。腕上，四十跳成四十一。

记账人没走，立等。满场眼睛顺老路捋：袖口的七，观察角的十三，对面的三十九。三处，一处也没动。

"未毕。续，次鸣。"

人与秤一齐拧回，杆上照旧差着那一丝。

应真往回走。几十步，还是一个字没说。到了垛前坐下，手搭上碗，一只一只，接着码。码到顶上那只，手还是悬了半息——这回，落得比先前那一下稳。

墙根那头，女孩冲他又点了一下头。这一回，点得不小。

鸣间不长。

碗声先续上。应真码碗，码得比先前慢——不是手上飘，是场里静，静得碗声显得响，他把动静收着使。

饿往第五日去。第四日末，人人学会了省：能坐着的，不站；能不抬的眼皮，不抬。水队排得比先前勤——兽嘴那点水压不住饿，能压一阵，是一阵。

道口还是仨。老者脸冲那截空，眼睛不挪；皮夹克坐对面，手摊在膝盖上；中间袖口拢着。瞧的照旧瞧，被瞧的照旧被瞧，谁也不说话。那截空，还是空的。

第九鸣贴着屋脊滚过来。记账人随鸣现身，秤落当间，杆上照旧差着那一丝。

"续。"

"谁先来，谁先说。"

道口那边，摊在膝盖上的手收起来了。

满场先是没动静——那位，四天晷没离过他的位。皮夹克起身，没看秤，先往中间那截袖口瞧了一眼。就一眼。袖口没动，老者也没回头。他从道口往当间走，几十步，走得比谁上秤都快，像去接一笔早就算好的账。

到秤前，他没看腕。三十九——这数他不用看，他记着。

"这题问来路。"开口还是那个不高的声，字是数着往外放的，"我的来路，打一个数上起。"

"我是数账的。"他把右手翻过来，虎口冲着满场——那层茧，头一回有人正眼细瞧，"不是干粗活磨的，是数出来的。筹码，票子，点子，一天过手几千遍，闭着眼不错数。"

"场子是六指的。他右手六个指头，摸牌比我数钱还快。他管场子，我管账。场子里外，就我俩心里有数。"

"那年腊月，他说家里有事，走三天，让我替他坐一夜账房。我替了。前半夜无事。后半夜最后一把，牌开完，账对不上——短了。"

他停了。满场都在等他说短多少。

"短多少，我数不出来了。"

"数了半辈子，就那一个数，摆在眼跟前的——黑的。"他不急不缓，"场子我记得，牌我记得，六指打的包、走的后门，我全记得。就那个数，黑的。"

"场子的规矩，账押在数账的人身上。他走他的，账落我背上。打那天起，上门的没断过。"

"路，背到这儿。后头是黑的。不添。"

话音落，秤动了。腕上，三十九跳成四十。

这一条路，满场扒拉指头的没处下手——黑的不是脸，不是日子，是个数。有眼睛顺带往答完的那几位身上过了一遍：答完了，往后是什么章程？没人问，也没处问。

记账人没走，立等。这回眼睛不用捋也知道往哪儿落——第五题就剩两处了：袖口的七，观察角的十三。一处比一处沉。

"未毕。续，次晷。"

人与秤一齐拧回，杆上照旧差着那一丝。

皮夹克往回走，不快不慢。到道口，坐下，手照旧摊在膝盖上。老者没回头。

道口，还是仨。

天黑透了。第五晷，在夜那头。
